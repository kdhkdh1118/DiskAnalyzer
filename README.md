# DiskAnalyzer
오픈소스 SW 팀 프로젝트 - 디스크 저장 공간 분석 프로그램

## 저장 공간 분석 초안 실행

Python 3.10 이상과 Rclone이 필요합니다. Rclone을 설치한 뒤 터미널에서
`rclone version`이 실행되는지 확인하세요.

저장소 폴더에서 다음 명령을 실행합니다.

```sh
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

브라우저에서 `http://localhost:8501`을 열고, 이 프로그램을 실행 중인
컴퓨터의 폴더 경로를 입력한 뒤 **폴더 분석 시작**을 누릅니다.
선택한 폴더 아래의 파일 수와 파일 크기 합계를 표시합니다.

`scanner.scan(폴더 경로)`는 분석 폴더, 파일별 상대경로·크기·수정 시각,
부분 스캔 여부를 반환합니다. 일반 스캔에서는 파일 해시를 계산하지 않습니다.

## 예외 안내와 트리맵

- 빈 폴더는 파일 수와 파일 크기 합계를 0으로 표시하고, 분석할 파일이 없다고 안내합니다.
- 폴더를 읽지 못하면 읽기·접근 권한과 경로를 확인하도록 안내합니다. 일부만 읽었을 때는
  읽은 파일만 집계했다는 경고를 표시하므로 전체 용량으로 해석하지 않아야 합니다.
- Plotly 트리맵은 현재 폴더와 하위 폴더에서 용량이 큰 파일을 최대 100개 표시하고,
  나머지 파일의 용량은 **기타** 하나로 합칩니다. 전체 용량과 파일 수 집계에는
  모든 파일을 포함합니다. 0 B 파일은 트리맵 면적이 없으므로 차트에서 제외합니다.
- 파일 크기가 모두 0 B이면 파일 수는 표시하고, 트리맵을 그릴 수 없다고 안내합니다.
- 폴더명에 포함된 공백을 보존하므로 입력한 경로 그대로 분석합니다.

## 스캔 기록 비교

- 폴더를 분석할 때마다 결과를 `data/disk_analyzer.duckdb`에 저장합니다.
  이 파일에는 개인 파일 경로가 들어 있으므로 Git에 올리지 않습니다(`.gitignore`).
- 같은 폴더를 다시 분석하면 바로 이전 기록과 비교하여, 현재 폴더 기준으로
  하위 폴더별 이전 크기·현재 크기·증감과 새로 생김/사라짐 여부를 표시합니다.
- 탐색기의 "경로로 복사"처럼 앞뒤에 따옴표가 붙은 경로도 그대로 분석할 수 있습니다.

## 테스트

```sh
python -m unittest discover -s tests -v
```

빈 폴더, 접근 제한 폴더, 부분 스캔, 파일이 많은 폴더의 집계와 트리맵 제한을
검증합니다. 실제 Rclone 테스트는 Rclone이 설치되어 있어야 실행됩니다.
